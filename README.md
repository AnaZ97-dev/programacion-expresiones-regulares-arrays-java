# Programación en Java: Expresiones Regulares y Arrays

Proyecto de programación en Java que cubre dos áreas fundamentales: el uso de **expresiones regulares** para la validación de datos y la manipulación de **arrays** (ordenación, inserción y borrado).

## 🛠️ Tecnologías y Herramientas
*   **Lenguaje:** Java (JDK 17)
*   **IDE:** Apache NetBeans
*   **Conceptos:** Expresiones Regulares (`Pattern`, `Matcher`), Arrays, Bucles anidados, Algoritmos de ordenación.

## 🎯 Funcionalidades y Conceptos Aplicados

1.  **Expresiones Regulares (Regex):**
    *   Uso de las clases `Pattern` y `Matcher` para validar fechas en formato `dd/mm/aaaa`.
    *   Uso del método `matches()` para comprobar si una cadena completa cumple el patrón.
    *   Uso de `find()` para buscar un patrón dentro de una subcadena.

2.  **Arrays y Algoritmos:**
    *   **Ordenación:** Implementación del algoritmo de ordenación por selección (bucle for anidado que compara y intercambia elementos usando una variable auxiliar).
    *   **Inserción:** Desplazamiento de elementos hacia la derecha para insertar un nuevo valor en un array con posiciones nulas.
    *   **Borrado:** Búsqueda de un elemento y desplazamiento de los elementos hacia la izquierda para eliminarlo, dejando la última posición a `null`.

## 🚀 Cómo ejecutar el proyecto
1. Abre el proyecto en Apache NetBeans.
2. Ejecuta las clases correspondientes (`Controlador`, `Ordenar`, `Insertar`, `Borrar`, etc.) como aplicaciones Java.
3. Observa los resultados por consola.
